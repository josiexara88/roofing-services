# San Francisco Roofing

A responsive, single-page roofing-services website inspired by San Francisco's distinctive homes, neighborhoods, and weather. Built with plain HTML, CSS, and JavaScript; no build step is required.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Customize before publishing

- Update the branding and service copy in `index.html` to match the business.
- The contact and service inquiry links currently point to `https://sanfranciscoroofing.us/`; replace them with the business's preferred contact destination if needed.
- Add verified contact information, license/insurance details, project photography, and any required disclosures before launch.
- Google Fonts are loaded remotely; the page falls back to system sans-serif fonts if they are unavailable.
